About

This is the blog for PlebOne, a small home for open-source Nostr tools and the community relay at relay.pleb.one.

It collects the posts about Nostr, Bitcoin and freedom tech that Tim writes for Nine Point Labs. Each one is first published there and also appears here, so everything on these topics is in one place. If you only care about this corner of the work, this is the feed to follow.

The posts are mostly release notes and build logs: what changed, why, and how to try it. If something is wrong or could be better, the code is on GitHub, and issues and pull requests are welcome.

You can follow along by RSS.
